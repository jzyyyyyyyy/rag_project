# PyCharm 完整操作步骤（超详细小白版）

> 本教程手把手教你在 PyCharm 中从零开始运行 RAG 知识库问答项目。
> 把每一步都写清楚了，跟着做就行。

---

## 第一部分：在 PyCharm 中打开项目

### 步骤1：打开 PyCharm

1. 双击桌面上的 PyCharm 图标，启动软件
2. 如果弹出"Import Settings"窗口，直接点 `OK` 或 `Do not import`
3. 等待 PyCharm 完全启动，看到欢迎界面

### 步骤2：打开项目文件夹

**方法A：从欢迎界面打开**
1. 在欢迎界面点击 `Open`（打开）
2. 在弹出的文件选择窗口中，找到项目文件夹 `rag_project`
   - 路径：`D:\informatics\RAG\rag_project`
3. 选中 `rag_project` 文件夹，点 `OK`
4. 如果弹出"Trust Project"（信任项目）窗口，点 `Trust Project`

**方法B：从菜单打开**
1. 顶部菜单栏点 `File` → `Open`
2. 选择 `rag_project` 文件夹，点 `OK`

### 步骤3：确认项目结构

打开后，看 PyCharm 左侧的项目文件列表（Project 面板），应该能看到：

```
rag_project/
├── config.py
├── build_database.py
├── chat.py
├── app.py
├── requirements.txt
├── README.md
├── knowledge_base/      （空文件夹，用来放文档）
└── docs/
    ├── 课程报告.md
    └── 答辩PPT文字内容.md
```

> 如果左侧看不到 Project 面板，点左下角的小方块图标，选 `Project`。

## 第二部分：配置 Python 解释器

### 步骤4：检查/配置 Python 解释器

1. 顶部菜单栏点 `File` → `Settings`（设置）
   - 或者按快捷键 `Ctrl + Alt + S`
2. 在左侧找到 `Project: rag_project` → `Python Interpreter`（Python 解释器）
3. 看右侧显示的 Python 版本
   - **如果已经显示 Python 3.9/3.10/3.11**：直接点 `Cancel` 关闭，跳到第三部分
   - **如果显示 No interpreter 或版本不对**：继续下面操作

### 步骤5：添加 Python 解释器（如果没有的话）

1. 在 Python Interpreter 页面，点右侧齿轮图标 ⚙️ → `Add`（添加）
2. 左侧选 `Virtualenv Environment`（虚拟环境）
3. 右侧选择：
   - `New`（新建）：位置默认就行
   - `Base interpreter`：下拉选你电脑上装的 Python 3.9+ 版本
   - 如果下拉里没有，点 `...` 手动找到 python.exe
4. 点 `OK`，等待虚拟环境创建完成
5. 回到 Settings 页面，点 `Apply` → `OK`

> 等待 PyCharm 右下角的索引进度条走完（可能需要1-2分钟）。

---

## 第三部分：安装依赖库

### 步骤6：打开 PyCharm 终端

1. 看 PyCharm 窗口底部，有一排标签：`Terminal`、`Python Packages`、`TODO` 等
2. 点击 `Terminal`（终端）标签
3. 底部会弹出一个命令行窗口
4. 确认终端开头显示的是项目路径，类似：
   ```
   (rag_project) D:\informatics\RAG\rag_project>
   ```
   - 前面有 `(rag_project)` 说明虚拟环境已激活，很好
   - 如果没有，也没关系，继续下一步

### 步骤7：安装所有依赖库

在终端里输入下面这行命令，然后按回车：

```bash
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

**操作细节：**
1. 把上面这行命令完整复制
2. 在终端里点鼠标右键（就是粘贴），或者按 `Ctrl + V`
3. 按回车键执行
4. 开始安装，会滚很多字，进度条慢慢走

**预期结果：**
- 安装过程会持续 3-10 分钟（取决于网速）
- 最后出现 `Successfully installed xxx` 一堆包名
- 没有红色的 `ERROR` 字样

**如果报错怎么办：**
- 网络错误：重新执行一遍命令
- 提示 pip 版本低：不用管，不影响
- 某个包装不上：单独装那个包，比如 `pip install chromadb -i 清华源`

## 第四部分：配置 DeepSeek API Key

### 步骤8：申请 DeepSeek API Key

1. 打开浏览器，访问：https://platform.deepseek.com/
2. 用手机号注册并登录
3. 登录后，左侧菜单点 `API Keys`
4. 点右上角 `创建新的API Key`
5. 名字随便写，比如"我的RAG项目"，点确认
6. **立刻复制生成的那串 `sk-xxxxxx`**，保存到记事本
   - 关掉弹窗就看不到了！一定要先复制

### 步骤9：在代码中填入 API Key

1. 在 PyCharm 左侧项目列表中，双击 `config.py` 打开它
2. 找到第4行：
   ```python
   DEEPSEEK_API_KEY = "sk-在这里替换成你自己的API-Key"
   ```
3. 把引号里的内容删掉，换成你自己的 API Key
   - 改完后类似：
   ```python
   DEEPSEEK_API_KEY = "sk-1234567890abcdefghijklmnopqrstuvwxyz"
   ```
4. 按 `Ctrl + S` 保存文件

## 第五部分：准备知识库文档

### 步骤10：放入知识库文档

1. 在 PyCharm 左侧找到 `knowledge_base` 文件夹
2. 右键它 → `Open In` → `Explorer`（在资源管理器中打开）
3. 会弹出一个文件夹窗口
4. 把你想让机器人学习的文档拖进去
   - 支持格式：`.pdf`、`.txt`、`.docx`、`.md`
   - 建议放 3-10 个文档，围绕一个主题
   - PDF 必须是可复制文字的，扫描版图片 PDF 不行
5. 放好后关掉文件夹窗口
6. 回到 PyCharm，右键 `knowledge_base` 文件夹 → `Synchronize 'knowledge_base'`（同步）
   - 或者直接点一下文件夹前面的小三角展开，就能看到你放的文件了

> 推荐：你可以把老师的几份课程 PDF 课件放进去，做一个"课程答疑助手"。

## 第九部分：常见问题排查

### 问题1：ModuleNotFoundError: No module named 'xxx'

**原因**：依赖库没装好，或者解释器不对
**解决**：
1. 确认终端前面有 `(rag_project)` 虚拟环境标识
2. 重新执行 `pip install -r requirements.txt -i 清华源`
3. 检查 Python Interpreter 设置（步骤4）

### 问题2：API Key 报错 / 认证失败

**原因**：API Key 填错了，或者没复制完整
**解决**：
1. 打开 config.py，检查 DEEPSEEK_API_KEY
2. 确认是 `sk-` 开头的一长串，没有多余空格
3. 去 DeepSeek 平台重新生成一个 Key

### 问题3：建库时卡在下载模型

**原因**：第一次运行要下载400MB的嵌入模型，网速慢
**解决**：耐心等，只要进度条在走就没问题，下载完以后就不用再下了。

### 问题4：PDF 读不出来 / 加载文档数为0

**原因**：PDF是扫描版图片，没有文字层
**解决**：换一个可复制文字的PDF，或者用TXT/Word文档

### 问题5：回答和文档内容不符 / 出现幻觉

**原因**：Prompt没生效，或者检索没找到相关内容
**解决**：
1. 确认 config.py 里 LLM_TEMPERATURE = 0.3（越低越严谨）
2. 把 RETRIEVAL_TOP_K 改成 5，多检索一些片段
3. 换个问法，用文档里的关键词提问

### 问题6：streamlit 命令找不到

**原因**：streamlit 没装成功
**解决**：终端执行 `pip install streamlit -i 清华源`，装完再试
